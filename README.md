# Task Board — Angular 17

A task board application built with Angular 17 as a learning project.

## Features

- Authentication with tokens and route guards
- Task board with forms for working with tasks
- State management with NgRx (store, effects, devtools)
- Internationalization with ngx-translate
- Server-side rendering (Angular SSR)
- Lazy-loaded routes and Angular Material UI

## Tech

Angular 17 · TypeScript · NgRx · RxJS · Angular Material · ngx-translate · Angular SSR · json-server

## Run locally

```bash
cd my-app
npm install
npm run json-auth   # mock API on json-server
npm start           # http://localhost:4200
```
